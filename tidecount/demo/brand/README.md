# Tideflow brand assets

The mark is a diving fish whose tail forms the T of Tideflow, going down through layers of tide.

| File | Use it for |
|---|---|
| `tideflow-icon.svg`, `tideflow-icon-1024.png` | The app icon with rounded corners and a transparent background: slides, posters, the Devpost thumbnail |
| `tideflow-icon-square.svg`, `tideflow-icon-square-1024.png` | The icon with square corners, for places that crop it themselves: profile pictures, app stores |
| `tideflow-lockup.svg`, `.png` | Icon and name, for light backgrounds |
| `tideflow-lockup-white.svg`, `.png` | Icon and name, for dark backgrounds |
| `tideflow-mark.svg`, `tideflow-mark-white.svg` | The fish alone in one colour, for small print or on top of a photo |

Prefer the SVGs, because they stay sharp at any size. The wordmark is Bricolage Grotesque ExtraBold converted to outlines, so it needs no font installed.

| Colour | Hex |
|---|---|
| Surface, the same as the app's accent | `#1F5EFF` |
| Middle tide | `#1745CC` |
| Deep tide | `#0F2F9E` |
| Ink, for the wordmark on light backgrounds | `#101828` |

Keep clear space of at least a quarter of the icon's width around it, and don't recolour, stretch or add effects to it.

The website's own icons are in `web/public/`. They use a simplified drawing with one wave and a larger fish, because they show at 16 to 48 pixels.
